# プルリクエスト下書きの作成

今現在のブランチで行った作業、コミットなどを元にプルリクの下書きを新規にpre_pr.mdとしてルートディレクトリに出力してください。

すでにルートディレクトリに`pre_pr.md`がある場合は更新してください。

.github/pull_request_template.md
はあくまで書き方のサンプル。
この構成や表現にこだわる必要はありません。

以下を意識してください。

- 何のための変更か、結果として何が変わるかが伝わるようにする
- 実装の詳細は、レビューに必要なものだけ残す
- 冗長な説明や重複は削り、できるだけ簡潔にする
- 重要な仕様・設計判断・前提条件・注意点は省略しない
- 元の文章にない仕様や事実を推測で追加しない
- 大まかにセクションをつかってカテゴリーわけしてほしい

細かすぎても読むのがしんどいため、要点を残しつつ粒度が大きく、ざっくりと大まかにわかれば十分
