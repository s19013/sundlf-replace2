# 存在しないurlにアクセス

エラー画面を表示して、ホーム画面へのもどるよう促す。

url:`/error`

url自体は1つで十分だと思う。
それで中身を変えれば十分

# 旧仕様url

新仕様urlにリダイレクトさせる機能が必要

旧:`Article/*` -> 新:`memo/`
旧:`BookMark/*` -> 新:`bookmark/`
旧:`Setting/*` -> 新:`setting/`

第2パスパラメータ以降は考慮しなくて良い
それぞれのルートに当たる部分にリダイレクト
