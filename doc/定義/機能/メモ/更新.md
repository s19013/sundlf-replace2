# できること

- タイトルを更新できる
- 本文を更新できる
- 星を更新できる
- タグを更新できる

# できないこと・対象外

- 他ユーザーのメモは更新できない
- ゴミ箱内のメモは更新できない
- 物理削除済みのメモは更新できない

# 仕様

ユーザーがタイトルを入力しなかった場合は、ユーザー側のタイムゾーンでの現在の日時をタイトルとする

### md方式

ユーザーはhtml化したときのプレビューを確認できる

###

現行では、別タブから戻ってきた場合に古い状態になっている場合があるもよう。
そのようなことが起きないように、常に新しい状態にしておきたい。
(キャッシュの仕業なのか、詳しい原因は不明)

しかし、ユーザーが未保存のデータを上書きをしたくもない。

###

別タブで開いている場合も、両方最新の状態にした。
