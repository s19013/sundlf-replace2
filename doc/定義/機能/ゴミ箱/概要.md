# 概要

画面から削除したメモ、ブックマークは論理削除扱いにして非表示にする。
論理削除したメモ、ブックマークはゴミ箱の中にあるという扱いになる。

## 対象データ

ログインユーザーが所有するメモ。
ログインユーザーが所有するブックマーク。

# 復元

ユーザーが論理削除を無効化し、ゴミ箱から取り出せる

# 強制削除

ユーザーが時間経過を待たずに削除できる

# 時間経過

30日経つと物理削除(完全削除)されゴミ箱からも消える
(タスクスケジュール)

## 期限警告機能

残り1週間で消える場合、警告する

## 削除時

タグデータも削除する

# 備考

ブックマーク、メモはそれぞれ別の画面で実装
