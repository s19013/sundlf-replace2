# メモ検索API

## 概要

条件を指定して、メモを検索できる

## 認証

ログイン必須

## メソッド・URL

`post /api/memos/search`

## リクエスト

詳しいことは後で決める

```json
{
  検索条件たち
}
```

## レスポンス

```json
[
  {
    メモ情報
    tags:[タグ情報]
  }
]
```

## エラー

| ステータス | 内容       |
| ---------- | ---------- |
| 401        | 未ログイン |

## 処理の流れ

1.  リクエスト取得
1.  条件に応じたクエリを組み立て
1.  検索
1.  レスポンス返却
