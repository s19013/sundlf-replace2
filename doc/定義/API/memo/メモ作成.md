# メモ作成API

## 概要

メモを作成する。

## 認証

ログイン必須

## メソッド・URL

post `/api/memos`

## リクエスト

```json
{
  "title": "タイトル",
  "body": "本文",
  "star": 3,
  "tag_ids": [1, 2, 3]
}
```

## バリデーション

| 項目       | 必須 | ルール               |
| ---------- | ---- | -------------------- |
| title      |      | 文字列、最大255文字  |
| body       |      | 文字列、最大20万文字 |
| star       | yes  | 整数、1〜5           |
| tag_ids    |      | 配列                 |
| tag_ids.\* |      | 存在するタグID       |

## レスポンス

```json
{
  "id": 1,
  "title": "タイトル"
}
```

## エラー

| ステータス | 内容                 |
| ---------- | -------------------- |
| 401        | 未ログイン           |
| 404        | メモが存在しない     |
| 422        | バリデーションエラー |

## 処理の流れ

1. リクエスト取得
1. 入力値を検証する
1. メモ情報を保存する
1. タグの紐付けを保存する
1. レスポンス返却

## 更新する項目

- メモ
  - 本文
  - タイトル
  - 星
  - 更新日時
  - 作成日時
- メモタグ中間テーブル
  - メモid
  - タグid
