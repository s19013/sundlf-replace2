# メモ取得

## 概要

ユーザーが登録したメモを閲覧できる

## 認証

ログイン必須。

## メソッド・URL

get `/api/memos/{id}`

## パスパラメータ

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | 対象ID |

## レスポンス

```json
{
    メモ情報,
    tags:[タグ情報,…]
}
```

## バリデーション

| 項目 | 必須 | ルール |
| ---- | ---- | ------ |
| id   | yes  | 文字列 |

## エラー

| ステータス | 内容             |
| ---------- | ---------------- |
| 401        | 未ログイン       |
| 404        | メモが存在しない |

## 処理の流れ

1. リクエスト取得
1. ユーザーがメモの持ち主か確認
1. レスポンス返却
