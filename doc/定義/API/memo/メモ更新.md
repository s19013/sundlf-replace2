# メモ更新API

## メソッド

PATCH /api/memos/{memo}

### 概要

指定したメモを更新する。

### メソッド・URL

`PATCH /api/memos/{memo}`

### 認証

ログイン必須。

### リクエスト

```json
{
  "title": "タイトル",
  "body": "本文",
  "star": 3,
  "tag_ids": [1, 2, 3]
}
```

## バリデーション

| 項目       | ルール                    |
| ---------- | ------------------------- |
| title      | 必須、文字列、最大255文字 |
| body       | 必須、文字列              |
| star       | 必須、整数、1〜5          |
| tag_ids    | 配列                      |
| tag_ids.\* | 存在するタグID            |

## レスポンス

```
{
  "id": 1,
  "title": "タイトル",
  "body": "本文",
  "star": 3,
  "tags": [
    {
      "id": 1,
      "name": "Laravel"
    }
  ],
  "created_at": "2026-05-05T10:00:00+09:00",
  "updated_at": "2026-05-05T10:30:00+09:00"
}
```

## エラー

| ステータス | 内容                 |
| ---------- | -------------------- |
| 401        | 未ログイン           |
| 404        | メモが存在しない     |
| 422        | バリデーションエラー |
