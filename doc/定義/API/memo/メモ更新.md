# メモ更新API

## 概要

指定したメモを更新する。

## 認証

ログイン必須。

## メソッド・URL

`PATCH /api/memos/{id}`

## リクエスト

```json
{
  "title": "タイトル",
  "body": "本文",
  "star": 3,
  "tag_ids": [1, 2, 3]
}
```

## パスパラメータ

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | 対象ID |

## バリデーション

| 項目       | ルール               |
| ---------- | -------------------- |
| title      | 文字列、最大255文字  |
| body       | 文字列、最大20万文字 |
| star       | 必須、整数、1〜5     |
| tag_ids    | 配列                 |
| tag_ids.\* | 存在するタグID       |

## レスポンス

```
{
  "id": 1,
  "title": "タイトル",
}
```

## エラー

| ステータス | 内容                 |
| ---------- | -------------------- |
| 401        | 未ログイン           |
| 404        | メモが存在しない     |
| 422        | バリデーションエラー |

## 処理概要

1. 対象メモを取得する
2. ログインユーザーの所有メモか確認する
3. ゴミ箱内のメモでないか確認する
4. 入力値を検証する
5. メモ情報を更新する
6. タグの紐付けを更新する
7. 更新結果を返す
