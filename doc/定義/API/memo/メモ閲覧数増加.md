# メモ作成API

## 概要

メモの閲覧数を1増やす。

## 認証

ログイン必須

## メソッド・URL

patch `/api/memos/{id}/count`

## リクエスト

なし

## バリデーション

| 項目 | 必須 | ルール |
| ---- | ---- | ------ |
| id   | yes  | 文字列 |

## レスポンス

なし

## エラー

| ステータス | 内容                          |
| ---------- | ----------------------------- |
| 401        | 未ログイン                    |
| 404        | メモが存在しない,他の人のメモ |
| 422        | バリデーションエラー          |

## 処理の流れ

1. リクエスト取得
1. 対象メモを取得する
1. ログインユーザーの所有メモか確認する
1. ゴミ箱内のメモでないか確認する
1. 入力値を検証する
1. 対応したメモを取得
1. 閲覧数を1増やす

## 更新する項目

- メモ
  - 閲覧数
