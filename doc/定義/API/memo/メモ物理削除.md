# メモ物理削除API

## 概要

指定したメモを物理削除する。

## 認証

ログイン必須

## メソッド・URL

`delete /api/memos/{id}/force`

## リクエスト

なし

## パスパラメータ

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | 対象ID |

## バリデーション

| 項目 | 必須 | ルール |
| ---- | ---- | ------ |
| id   | yes  | 文字列 |

## レスポンス

なし

## エラー

| ステータス | 内容                          |
| ---------- | ----------------------------- |
| 401        | 未ログイン                    |
| 404        | メモが存在しない,他の人のメモ |
| 422        | バリデーションエラー          |

## 処理の流れ

1. リクエスト取得
1. 対象メモを取得する
1. ログインユーザーの所有メモか確認する
1. ゴミ箱内のメモでないか確認する
1. 入力値を検証する
1. メモを物理削除
