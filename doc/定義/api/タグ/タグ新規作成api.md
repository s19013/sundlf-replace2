# api名

tags.create

# 概要

このAPIはタグの新規作成を行います。

# エンドポイント

post `/api/tags/`

# 認証

必須

# リクエストボディ

```json
{
  "name": "タグ名"
}
```

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{タグ名}を登録しました。"]
}
```

# バリデーション

name:['required']

# 処理の流れ

- バリデーションチェック
- 重複チェック
- 登録
- レスポンス返却

# エラー

## 重複

すでに同じユーザーが同じ名前のタグを登録していたらエラーを返す

ステータスコード:409

```json
{
  "messages": ["{タグ名}はすでに登録されています。"]
}
```
