# api名

tags.delete

# 概要

このAPIはタグの削除を行います。

# エンドポイント

delete `/api/tags/{id}`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | タグID |

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{タグ名}に削除しました。"]
}
```

# バリデーション

id:['required']

# 処理の流れ

- バリデーションチェック
- タグ情報取得
- タグの作成者idとログイン者のid確認
- タグテーブルから削除
- 中間テーブルから削除
- レスポンス返却

# エラー

## 削除対象のタグが見つからない

ステータスコード:404

```json
{
  "messages": ["削除に失敗しました。"]
}
```

## タグの作成者とログイン者のidが違う

ステータスコード:403

```json
{
  "messages": ["このタグは削除できません。"]
}
```
