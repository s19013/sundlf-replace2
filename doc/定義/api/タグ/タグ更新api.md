# api名

tags.update

# 概要

このAPIはタグの更新を行います。

# エンドポイント

patch `/api/tags/{id}`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | タグID |

※ URLのパスパラメータのため型はstring。数値形式であることはバリデーション(`integer`)で検証する。

# リクエストボディ

```json
{
  "name": "新タグ名"
}
```

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{旧タグ名}を{新タグ名}に更新しました。"]
}
```

# バリデーション

name:['required']
id:['required', 'integer']

# 処理の流れ

- バリデーションチェック
- 旧タグ名取得
- 旧タグの作成者idとログイン者のid確認
- 重複チェック
- 更新
- レスポンス返却

# エラー

## 重複

すでに同じユーザーが同じ名前のタグを登録していたらエラーを返す

ステータスコード:409

```json
{
  "messages": ["{新しいタグ名}はすでに登録されています。"]
}
```

## 更新対象のタグが見つからない

ステータスコード:404

```json
{
  "messages": ["タグが見つかりませんでした。"]
}
```

## タグの作成者とログイン者のidが違う

他人のタグの存在を推測できないようにするため、403ではなく404を返す。本文も「対象のタグが見つからない」場合と同一にする。

ステータスコード:404

```json
{
  "messages": ["タグが見つかりませんでした。"]
}
```
