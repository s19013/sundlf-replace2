# api名

tags.update

# 概要

このAPIはタグの更新を行います。

# エンドポイント

patch `/api/tags/{id}`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | タグID |

# リクエストボディ

```json
{
  "name": "新タグ名"
}
```

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{旧タグ名}を{新タグ名}に更新しました。"]
}
```

# バリデーション

name:['required']
id:['required']

# 処理の流れ

- バリデーションチェック
- 旧タグ名取得
- 旧タグの作成者idとログイン者のid確認
- 重複チェック
- 更新
- レスポンス返却

# エラー

## 重複

すでに同じユーザーが同じ名前のタグを登録していたらエラーを返す

ステータスコード:409

```json
{
  "messages": ["{新しいタグ名}はすでに登録されています。"]
}
```

## 更新対象のタグが見つからない

ステータスコード:404

```json
{
  "messages": ["更新に失敗しました。"]
}
```

## タグの作成者とログイン者のidが違う

ステータスコード:403

```json
{
  "messages": ["このタグは更新できません。"]
}
```
