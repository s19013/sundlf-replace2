# api名

memos.complete-deletion

# 概要

このAPIは**論理削除された**メモ完全削除を行います。

# エンドポイント

delete `/api/memos/{id}/completely`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | メモID |

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{タイトル名}を完全削除しました。"]
}
```

# バリデーション

id:[required]

# 処理の流れ

- バリデーションチェック
- メモ情報取得
- メモの作成者idと送信者のid確認
- メモが論理削除状態化確かめる
- 削除処理
  - 中間テーブル含める
- レスポンス返却

# エラー

## メモの作成者と送信者のidが違う

ステータスコード:403

```json
{
  "messages": ["このメモは更新できません。"]
}
```

## 対象が論理削除状態ではなかった

ステータスコード 422

```json
{
  "messages": ["このメモは削除できません。"]
}
```
