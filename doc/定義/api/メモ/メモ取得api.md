# api名

memos.fetch

# 概要

このAPIはメモを取得します。

# エンドポイント

get `/api/memos/{id}`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | メモID |

# レスポンス

ステータスコード:200

```json
{
  "memo": "メモモデル"
}
```

# バリデーション

id:['required']

# 処理の流れ

- メモの作成者idと送信者のid確認
- 取得作業
- レスポンス返却

# エラー

## メモが取得できなかった

論理削除済み、物理削除済みなど

ステータスコード:404

```json
{
  "messages": ["メモが見つかりませんでした。"]
}
```

## メモの作成者と送信者のidが違う

ステータスコード:403

```json
{
  "messages": ["このメモは取得できません。"]
}
```
