# api名

memos.fetch

# 概要

このAPIはメモを取得します。

# エンドポイント

post `/api/memos/{id}/salvage`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | メモID |

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{タイトル名} を復元しました。"]
}
```

# バリデーション

id:['required']

# 処理の流れ

- メモの作成者idと送信者のid確認
- 復元作業
- レスポンス返却

# エラー

## メモが取得できなかった

物理削除済みなど

ステータスコード:404

```json
{
  "messages": ["メモが見つかりませんでした。"]
}
```

## メモの作成者と送信者のidが違う

ステータスコード:403

```json
{
  "messages": ["このメモは復元できません。"]
}
```
