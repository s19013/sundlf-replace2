# api名

memos.delete

# 概要

このAPIは対象メモの**論理削除**を行います。

# エンドポイント

delete `/api/memos/{id}`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | メモID |

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{タイトル名} を削除しました。"]
}
```

# バリデーション

id:['required']

# 処理の流れ

- メモ取得
- メモの作成者idとログイン者のid確認
- 削除作業
- レスポンス返却

# エラー

## メモの作成者とログイン者のidが違う

ステータスコード:403

```json
{
  "messages": ["このメモは削除できません。"]
}
```
