# api名

memos.delete

# 概要

このAPIは対象メモの**論理削除**を行います。

# エンドポイント

delete `/api/memos/{id}`

# 認証

必須

# パスパラメータ

最新の詳細な型はscramble生成のOpenAPI/schema.d.ts参照

| 名前 | 型     | 必須 | 説明   |
| ---- | ------ | ---- | ------ |
| id   | string | yes  | メモID |

# レスポンス

ステータスコード:200

```json
{
  "messages": ["{タイトル名} を削除しました。"]
}
```

# バリデーション

id:['required', 'integer']

# 処理の流れ

- メモ取得
- メモの作成者idとログイン者のid確認
- `DB::transaction`内で以下をまとめて実行する
  - 対象メモを行ロック(`lockForUpdate`)して再取得
    - 既に論理削除または物理削除されていた場合(同時実行で先に削除された場合など)は、何もせずに終了する
  - 紐付いているタグの使用回数(`count`)を減算
  - 削除作業(論理削除)
- レスポンス返却

# エラー

## メモが取得できなかった

物理削除済み、論理削除済みなど

ステータスコード:404

```json
{
  "messages": ["メモが見つかりませんでした。"]
}
```

## メモの作成者とログイン者のidが違う

他人のメモの存在を推測できないようにするため、403ではなく404を返す。

ステータスコード:404

```json
{
  "messages": ["このメモは削除できません。"]
}
```

# 備考

- タグの使用回数(`count`)の減算は、完全削除時ではなく**論理削除時**に行う。復元時に加算して元に戻す(`メモ復元api.md`参照)。
- 行ロック後に再確認するのは、同時に削除リクエストが来た場合にタグの使用回数が二重に減算されることを防ぐため。
