# メモ更新画面

## 目的

既存メモを編集する。

## URL

`/memos/{memo}/edit`

## 表示項目

- タイトル入力欄
- 本文入力欄
- 星入力
- タグ入力
- 更新ボタン
- キャンセルボタン

## 初期表示時の処理

1. URLからメモIDを取得する
2. `GET /api/memos/{memo}` を呼び出す
3. 取得したメモ情報をフォームに設定する

## ユーザー操作

### 更新ボタン押下

1. フォームの入力内容を取得する
2. `PATCH /api/memos/{memo}` を呼び出す
3. 成功時はメモ詳細画面へ遷移する
4. 失敗時はエラーを表示する

### キャンセルボタン押下

メモ詳細画面へ戻る。

## 使用API

- `GET /api/memos/{memo}`
- `PATCH /api/memos/{memo}`

## 状態ごとの表示

### 読み込み中

ローディングを表示する。

### 取得成功

フォームにメモ情報を表示する。

### 取得失敗

エラーメッセージを表示する。

### 更新中

更新ボタンを無効化する。

### 更新成功

メモ詳細画面へ遷移する。

### 更新失敗

エラーメッセージを表示する。

## バリデーションエラー表示

各入力欄の下にエラーメッセージを表示する。

## 画面遷移

| 操作         | 遷移先                  |
| ------------ | ----------------------- |
| 更新成功     | メモ詳細画面            |
| キャンセル   | メモ詳細画面            |
| メモ取得失敗 | 404画面、または一覧画面 |
