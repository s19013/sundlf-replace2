# 画面名

memo.edit

# url

`memo/edit/{id}`

# 認証

必須

# 表示項目

- タイトル入力フォーム
- 本文入力フォーム
- タグボタン
- 紐付けているタグ
- 星プルダウン
- 削除ボタン
- 保存ボタン
- md,html切り替えボタン
- 作成日
- 更新日

# 機能(ユーザーができること)

- 削除
- 更新
- タグ紐付け
- md,html切り替え

# 機能(ユーザーができないこと)

自動入力機能
html変換

# 初期表示時の処理

メモ取得apiを呼び出す

# 使用API

- [メモ取得api](../../../api/メモ/メモ取得api.md)
- [メモ更新api](../../../api/メモ/メモ更新api.md)

# レスポンス受取後

## メモ取得api

### エラー時

エラー画面へリダイレクト

## メモ更新api

スナックバー表示

## メモ削除api

検索画面へリダイレクト(replace())
検索画面でスナックバー表示

# 行動

## 削除ボタン 押下

警告モーダルを表示

## md,html切り替えボタン 押下

mdをhtmlに変換して表示を切り替える(フロント側で変換)

# 備考

## 自動入力

メモ更新api送信前に、ユーザーがタイトルを入力しなかった場合は、ユーザー側のタイムゾーンでの現在の日時をタイトルとする

## md方式

md方式で書いて、htmlに変換することを想定している
ただし、改行はエンターも対象

## 別タブ同期(未解決課題)

別タブで同じメモを開いている場合、一方が古い状態のまま表示され続けることがある。常に最新の状態にしておきたいが、具体的な実現方式(フォーカス時再取得、ポーリング等)は未定のため別途検討する。

## 何かしらのapi実行中

一切の行動を禁止させる
