# 画面名

memo.edit

# url

`memo/edit/{id}`

# 認証

必須

# 表示項目

- タイトル入力フォーム
- 本文入力フォーム
- タグボタン
- 紐付けているタグ
- 星プルダウン
- 削除ボタン
- 保存ボタン
- md,html切り替えボタン
- 作成日
- 更新日

# 機能(ユーザーができること)

- 削除
- 更新
- タグ紐付け
- md,html切り替え

# 機能(ユーザーができないこと)

自動入力機能
html変換処理

# 初期表示時の処理

メモ取得apiを呼び出す
メモの`updated_at`を`fetched_at`へ保存

# 使用API

- [メモ取得api](../../../api/メモ/メモ取得api.md)
- [メモ更新api](../../../api/メモ/メモ更新api.md)
- [メモ削除api](../../../api/メモ/メモ削除api.md)

# レスポンス受取後

## メモ取得api

md方式で表示

### エラー時

エラー画面へリダイレクト

## メモ更新api

スナックバー表示
メモの`updated_at`を`fetched_at`へ保存

### エラー時

#### 409

本文入力フォームをgit conflictのような表示にする
[参考](../../../機能/検討中/解決済み_別タブ同期方式の検討/chatgpt_参考資料.md)

## メモ削除api

検索画面へリダイレクト(replace())
検索画面でスナックバー表示

# 行動

## 削除ボタン 押下

警告モーダルを表示

### 同意後

検索画面へリダイレクト

## md,html切り替えボタン 押下

mdをhtmlに変換して表示を切り替える(フロント側で変換)

## 編集画面へフォーカス状態になった

`fetched_at`付きでメモ取得apiを呼び出す
編集済みの場合、「他のタブで更新されました。反映しますか?」とモーダルを出す。
このモーダルに同意した場合、タイトル、紐付けているタグ、本文すべてを上書きする

## 何かしらのapi実行中

一切の行動を禁止させる

# 備考

## 自動入力

メモ更新api送信前に、ユーザーがタイトルを入力しなかった場合は、ユーザー側のタイムゾーンでの現在の日時をタイトルとする

## md方式

md方式で書いて、htmlに変換することを想定している
ただし、改行はエンターも対象

## 競合状態

ユーザーは競合状態かわからないので、どこかに競合状態とはどんな状態か、何をすれば良いのかを記したページへのリンクを出現させる
