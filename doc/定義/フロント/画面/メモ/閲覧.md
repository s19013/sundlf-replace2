# 画面名

memo.viewer

# url

`memo/view/{id}`

# 認証

必須

# 表示項目

- タイトル
- 本文
- 紐付けているタグ
- 星
- 作成日
- 更新日
- 削除ボタン
- 編集ボタン

# 機能(ユーザーができること)

null

# 機能(ユーザーができないこと)

html変換
閲覧数を増やす

# 初期表示時の処理

メモ取得apiを呼び出す
メモ閲覧数増加apiを呼び出す

# 使用API

- [メモ取得api](../../../api/メモ/メモ取得api.md)
- [メモ閲覧数増加api](../../../api/メモ/メモ閲覧数増加api.md)

# レスポンス受取後

## メモ取得api

mdをhtmlに変換

### エラー時

エラー画面へリダイレクト

## メモ閲覧数増加api

完全に裏で動くapiなので何もしない。
エラーが起きても無視して問題ない。

# 行動

## 削除ボタン 押下

警告モーダルを表示
