# 画面名

memo.search

# url

`memo/search`

# 認証

必須

# 表示項目

- 検索フォーム
- 検索ボタン
- 詳細検索ボタン
- タグボタン
  - 選択されたタグ
- ソートプルダウン
- 検索数プルダウン
- 星プルダウン
- 検索対象ラジオボタン
- タグ無しチェックボックス
- ページネーション
- メモ情報
- ゴミ箱ボタン

### メモ情報

- タイトル
- 閲覧数
- 星
- 更新日
- 作成日
- 編集ボタン

# 機能(ユーザーができること)

- 検索

# 機能(ユーザーができないこと)

null

# 初期表示時の処理

メモ検索api実行

# 使用API

[メモ検索api](../../../api/メモ/メモ検索api.md)

# レスポンス受取後

## メモ検索api

クエリに応じてプルダウンなどの値を変化させる

# 行動

## 詳細検索ボタン 押下

詳細検索画面へ遷移

## タグボタン 押下

タグモーダルを表示

## タグ無しチェックボックス 押下

タグボタンを非活性化

## メモ情報 押下

閲覧画面へ遷移

## ゴミ箱ボタン 押下

ゴミ箱画面へ遷移

## 何かしらのapi実行中

一切の行動を禁止させる
