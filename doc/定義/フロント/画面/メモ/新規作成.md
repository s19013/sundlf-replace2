# 画面名

memo.create

# url

`memo/create`

# 認証

必須

# 表示項目

- タイトル入力フォーム
- 本文入力フォーム
- 星プルダウン
- タグボタン
- 紐付けているタグ
- 削除ボタン
- 保存ボタン
- md,html切り替えボタン

# 機能(ユーザーができること)

- 削除
- 保存
- タグ紐付け
- md,html切り替え

# 機能(ユーザーができないこと)

自動入力機能

# 初期表示時の処理

html変換

# 使用API

- [メモ新規作成api](../../../api/メモ/メモ新規作成api.md)
- [メモ更新api](../../../api/メモ/メモ更新api.md)

# レスポンス受取後

## メモ新規作成api

スナックバー表示

レスポンスの中のidをメモリ上に保管
以降、メモ新規作成apiではなくメモ更新apiを使う

## メモ更新api

スナックバー表示

## メモ削除api

検索画面へリダイレクト(replace())
検索画面でスナックバー表示

# 行動

## 削除ボタン 押下

警告モーダルを表示

## md,html切り替えボタン 押下

mdをhtmlに変換して表示を切り替える(フロント側で変換)

# 備考

## 自動入力

メモ新規作成api送信前に、ユーザーがタイトルを入力しなかった場合は、ユーザー側のタイムゾーンでの現在の日時をタイトルとする

## md方式

md方式で書いて、htmlに変換することを想定している
ただし、改行はエンターも対象

## 何かしらのapi実行中

一切の行動を禁止させる
