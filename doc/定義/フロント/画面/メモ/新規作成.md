必須

- タイトル入力フォーム
- 本文入力フォーム
- 星プルダウン
- タグボタン
- 紐付けているタグ
- 削除ボタン
- 保存ボタン
- md,html切り替えボタン

# 機能(ユーザーができること)

- 削除
- 保存
- タグ紐付け
- md,html切り替え

# 機能(ユーザーができないこと)

自動入力機能

# 初期表示時の処理

html変換

# 使用API

- メモ新規作成api
- メモ更新api
- メモ削除api

# 行動

## 削除ボタン 押下

警告モーダルを表示

# 備考

## 自動入力

メモ新規作成api送信前に、ユーザーがタイトルを入力しなかった場合は、ユーザー側のタイムゾーンでの現在の日時をタイトルとする

## md方式

md方式で書いて、htmlに変換することを想定している
ただし、改行はエンターも対象

## 一度保存した後

メモ新規作成apiで、メモのidが渡される(画面遷移しない)
その後の保存では、メモ更新apiを使う
