# 画面名

memo.trash-box

# url

`memo/trash-box`

# 認証

必須

# 表示項目

- 検索フォーム
- 検索ボタン
- 詳細検索ボタン
- タグボタン
  - 選択されたタグ
- ソートプルダウン
- 検索数プルダウン
- 星プルダウン
- 検索対象ラジオボタン
- タグ無しチェックボックス
- ページネーション
- メモ情報

### メモ情報

- 完全削除ボタン
- 復元ボタン
- タイトル
- 閲覧数
- 星
- 更新日
- 作成日

# 機能(ユーザーができること)

- 検索
- 完全削除
- 復元

# 機能(ユーザーができないこと)

null

# 初期表示時の処理

メモ検索api実行
クエリに応じてプルダウンなどの値を変化させる

期限が近ければ、メモ情報のバックグランドを赤くする

# 使用API

- [メモ検索api](../../../api/メモ/メモ検索api.md)
- [メモ完全削除api](../../../api/メモ/メモ完全削除api.md)
- [メモ復元api](../../../api/メモ/メモ復元api.md)

# レスポンス受取後

## メモ検索api

クエリに合わせてフォーム類を変化
結果表示

## メモ完全削除api

スナックバー表示
メモ検索api

## メモ復元api

スナックバー表示
メモ検索api

# 行動

## タグボタン 押下

タグモーダルを表示

## タグ無しチェックボックス 押下

タグボタンを非活性化

## 完全削除ボタン 押下

警告モーダル表示

## 何かしらのapi実行中

一切の行動を禁止させる
