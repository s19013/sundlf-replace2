# 画面名

memo.search.advanced

# url

`memo/search/advanced`

# 認証

必須

# 表示項目

- 検索フォーム
- 作成日範囲フォーム
- 更新日範囲フォーム
- 検索ボタン
- 完全一致タグボタン
  - 選択されたタグ
- 除外タグボタン
  - 選択されたタグ
- 部分一致タグボタン
  - 選択されたタグ
- ソートプルダウン
- 検索数プルダウン
- 星プルダウン
- 検索対象ラジオボタン
- タグ無しチェックボックス
- ページネーション

# 機能(ユーザーができること)

- 検索

# 機能(ユーザーができないこと)

null

# 初期表示時の処理

クエリに応じてプルダウンなどの値を変化させる

# 使用API

[メモ検索api](../../../api/メモ/メモ検索api.md)

# レスポンス受取後

## メモ検索api

検索画面へリダイレクトさせる

# 行動

## 完全一致タグボタン 除外タグボタン 部分一致タグボタン 押下

タグモーダルを表示

## タグ無しチェックボックス 押下

完全一致タグボタン 除外タグボタン 部分一致タグボタンを非活性化

## 何かしらのapi実行中

一切の行動を禁止させる
