# 画面名

tags.search

# url

`tags`

# 認証

必須

# 表示項目

- 検索フォーム
- 検索ボタン
- 削除ボタン
- 更新ボタン
- 新規作成ボタン
- ページネーション
- 警告モーダル
- 更新モーダル
- 新規作成モーダル

## タグ情報

- タグ名
- 使用数
- 作成日
- 更新日

# 機能(ユーザーができること)

- タグ検索
- 新規作成
- 削除
- 更新

# 機能(ユーザーができないこと)

null

# 初期表示時の処理

- タグ検索apiを呼び出す

# 使用API

- [タグ検索api](../../../api/タグ/タグ検索api.md)

# レスポンス受取後

## タグ検索api

クエリに合わせてフォーム類を変化
結果表示

# アクション

## 新規作成ボタン 押下

新規作成モーダル表示

## 更新ボタン 押下

更新モーダル表示
モーダルへタグ情報を渡す

## 削除ボタン 押下

警告モーダル表示
モーダルへタグ情報を渡す

## 何かしらのapi実行中

一切の行動を禁止させる

# 備考

## 更新、新規作成

更新、新規作成は新しい画面を作成せず、モーダルだけで済ます。
