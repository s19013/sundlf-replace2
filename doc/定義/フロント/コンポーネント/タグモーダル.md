# 表示項目

- 検索フォーム
- 検索ボタン
- 新規作成ボタン
- 新規作成フォーム
- タグ情報
- 閉じるボタン

### タグ情報

- タグ名
- チェックボックス

# 機能(ユーザーができること)

- タグのつけ外し
- タグ検索
- タグの新規作成

# 機能(ユーザーができないこと)

検索のキャッシュ
検索処理
タグのソート

# 初期表示時の処理

全タグ取得apiを実行
タグ情報たちをキャッシュに保存する

# 使用API

- [全タグ取得api](../../api/タグ/全タグ取得api.md)
- [タグ新規作成api](../../api/タグ/タグ新規作成api.md)

# レスポンス受取後

## タグ新規作成api

新規作成フォーム表示を非表示
スナックバー表示

# 行動

## 検索ボタン 押下

**フロントエンド側**で検索処理を実行

## 新規作成ボタン 押下(1回目)

新規作成フォーム表示

## 閉じるボタン 押下

モーダルを呼び出した画面に、今紐付け状態のタグ名をタグ名でソートした状態で渡す

## 何かしらのapi実行中

一切の行動を禁止させる

# 備考

モーダルの外側をクリックしても閉じない
